# 当前版本与性能口径

截至 2026-10-29，最近一项实物验收为“弯曲和伸直均正常”。当前源清单为 current_sources.json（原完整工程中的证据）。

## 功能与软硬件划分

- 语音问卷、按键流程、相机采集、眼部推理、网页报告与手势状态机位于 PS。
- PL 保持 UART、两路 I2C、按钮 GPIO；额外提供掌检测深度卷积核。
- 掌检测仅第 3、7、11、21、25、29 号 ONNX 节点使用 PL，其余算子在 CPU。
- 关键点网络在 CPU 使用 ncnn FP32；输出界面隐藏 21 点，内部关键点继续参与姿态计算。
- 最新跟踪修订保留旋转 ROI 的真实角点，周期掌检测漏检时继续使用本帧通过验证的关键点，低置信度时做一次有界裁剪重试。
