## 来源

- **睑裂斑 / 翼状胬肉 / 结膜下出血**：旧数据集 `dataset6.npz`（160×160，含 114 灰边 letterbox，与原训练输入一致）；
- **麦粒肿 / 睑缘炎 / 泪囊炎**：2026-10 训练集主图（去重后 139 张；5 张临床补充未参与训练，故未放进来）；
- **正常眼**：`normal_500_20261023`（Hugging Face 340 + SLID 160）。

## 说明

- 旧数据集是多标签：一张图可能同时有睑裂斑/翼状胬肉/结膜下出血。为保持每个文件只出现一次，这里按**主标签（argmax）**归类；完整标签见 `labels.csv` 的 `labels` 列。
- 旧图是 160×160 的预处理数组，带灰色补边，与训练时输入一致；如需美观可自行裁掉灰边，但会改变训练数据。
- 正常眼两来源域差异较大（手机外眼照 vs 裂隙灯），训练时建议分别加权或做域平衡。
- 版权/许可：旧数据与正常眼均来自公开网络/公开数据集，正式发表或商用前请核对原始许可；本集仅供研究、教学和模型调试。
