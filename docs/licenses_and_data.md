# 授权和数据范围

项目整体许可证尚未确定，本次未替作者选择 MIT、Apache 或其他整体许可。首次协作建议私有仓库；公开前维护者应决定项目许可证，并逐项确认第三方源码、模型、固件及数据的再分发条件。

随源保留 data/third_party/ncnn_license.txt 和板端库旁的 ncnn_license.txt，第三方源代码原有版权头不删除。这些许可不能自动覆盖其他模型、训练图片、固件或整个工程。

数值测试样本仅保留回归所需的 at/event/features，不含原图和问卷。根据项目维护者本次同步要求，`training set/` 已纳入七类图像训练集（2053 张）；其来源和使用说明见该目录 README。现场检查照片、用户检查报告、原始日志与历史对话未纳入本仓库或资源包。实际权限与来源仍由项目维护者记录。

资源包是已有项目文件的本地整理副本，生成资源包不代表已获得公开发布授权。只在授权范围内通过私有 Release 或受控渠道交付；七类图像与原有划分索引已随仓库提供；原训练缓存和检查点另行管理。图片来源说明不等同于统一的再分发或商业使用许可，保留训练集原始许可说明。
